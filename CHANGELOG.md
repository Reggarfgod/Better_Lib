# Better_Lib Changelog

## Version 1.0.112 (Minecraft 1.21.1)
- Modern two-column Minecraft configuration dashboard UI with category sidebar, real-time search, and custom controls.
- Full support for Booleans (toggle switches), Numbers (sliders), Dropdowns (cycling selectors), Enums, Colors, and Text fields.
- Multi-loader support across Fabric, Forge, and NeoForge on Java 21.
- Welcome Popup API with persistent player data, custom network payload sync, themes, and multi-mod support.
- Automated GitHub Actions build and release workflows.
